# 知識小花園·作業守護台

一款把「寫功課」變成守護戰的兒童教育網頁遊戲。孩子完成真實功課後，家長後台簽名，遊戲裡的食蟲植物就把瞌睡怪打退；練習場答題賺陽光，兌換真實獎勵。

## 特色
- **8 種雨林食蟲植物**（原創，非 PvZ 改版）對抗瞌睡怪
- **功課 / 練習場分離**：功課是真實學校作業，遊戲不模擬答題內容；練習場是遊戲內答題加分
- **陽光經濟護欄**：每日獲取上限 250 + 重刷舊題收益衰減，防通膨
- **存檔可靠**：IndexedDB 主存 + localStorage 兜底 + 家長後台一鍵備份（JSON 下載）
- **PWA**：可加到手機桌面當 APP 使用（需普通模式，非私密瀏覽）
- **內建使用說明書**：首裝自動彈一次，首頁「❓ 怎麼玩」隨時可查

## 年齡分級
L1 幼幼(3-5) / L2 低年級(6-8) 不限時；L3~L5(國中) 限時，題庫量隨級調整。涵蓋國語 / 數學 / 英文 / 知識，含成語、詞彙、閱讀測驗、英文閱讀與文法。

## 執行方式
- 直接用瀏覽器打開 `pvz-homework-v10.html`
- 或部署 `deploy/` 目錄（含 `manifest.json` / `sw.js` / `icon-512.png`）啟用 PWA 安裝
